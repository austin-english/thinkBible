# Task: one question, worded for readers of the KJV

ThinkBible readers choose their translation, BSB or KJV, and see each question beside their own
text. This question was written from the BSB. Code found that it uses a word a KJV reader won't
find in their verses: a quoted phrase the KJV words differently ('I am willing', where the KJV has
'I will'), or a name the KJV spells differently (Elijah, which the KJV's New Testament calls
Elias).

Write the same question for a KJV reader. Use the KJV's own words for what the question quotes or
names, taken from the KJV verses given, and keep everything else exactly as it is: the same
sentences, the same plain modern English, the same ending. Keep quoted words in single quotation
marks ('like this').

If the question already reads naturally to someone holding the KJV (an everyday word, or a
spelling any reader would recognise), return it unchanged.
