# Task: does each answer reach its key ideas?

You are given questions a typical reader answered, each with the key ideas it aims at. For each
answer, list the IDs of the target key ideas the answer really reaches: it makes the same point,
in any words. An answer that only touches the topic, or reaches the idea only by a lucky guess
the reader says they're unsure of, doesn't reach it. Judge only the listed target ideas.
