# Tasks: Book-Feel Feed and Chapter Panel

**Input**: Design documents from `specs/002-reader-read-mode/`: [plan.md](plan.md),
[spec.md](spec.md), [research.md](research.md), [data-model.md](data-model.md),
[contracts/](contracts/), [quickstart.md](quickstart.md)

**Tests**: Included. The constitution requires contract tests for the pack schema on the app side
and unit tests for business rules; SC-004 needs a pagination test over all of Mark. Write each
story's tests first and confirm they fail before implementing. Package tests use Swift Testing
(`import Testing`) and run with `swift test`; app tests run on the `iPhone 16 Pro` simulator.

**Organization**: Grouped by user story (US1–US5). US6 (the `…` menu) and "Notify me" are
deferred until after the prototype test (spec clarifications) and have no tasks here.

**Design source**: `docs/design/README.md` (Tokens, Type, Layout › Header, Feed, Card, Chapter
panel, Send, Accessibility) and `docs/design/screens/01-feed.png`, `02-page-2.png`,
`07-chapter-picker.png`, `08-book-list.png`, `09-genesis.png`. Read the README section and look at
the screen before building each view.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: Can run in parallel (different files, no dependency on unfinished tasks).
- **[Story]**: US1–US5, as in spec.md.
- Paths are relative to the repo root.
- Swift: language mode 6 (strict concurrency), iOS 17 deployment target, Observation (`@Observable`),
  no third-party packages, no hard-coded colors (DesignSystem tokens only).

## Dependencies and execution order

### Phases

- **Setup (Phase 1)**: none. T003 needs T002; T009 needs T003 and T007; T008 needs T007.
- **Foundational (Phase 2)**: needs Setup. Blocks every story.
- **US1 (Phase 3)**: needs Foundational. It is the MVP and the base for the others: US2, US3 and US5
  need its feed and card.
- **US2 (Phase 4)**, **US3 (Phase 5)**: need US1; independent of each other.

  and US3. Bundled reading already works after Phase 2, so US4 adds downloads and updates.
- **US5 (Phase 7)**: needs US1's card.
- **Polish (Phase 8)**: after the stories it covers.

Tests first and failing, then models, then views, then wiring. A story is done at its checkpoint.

  (ContentKit).
